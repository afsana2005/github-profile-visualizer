SETUP (Windows / VS Code)
1. Extract this ZIP and open the extracted project folder in VS Code.
2. Create backend/.env (inside the backend folder) with:
   PORT=5000
   FRONTEND_ORIGIN=http://localhost:5173
   GEMINI_API_KEY=YOUR_PRIVATE_GEMINI_KEY
   GEMINI_MODEL=gemini-3.5-flash-lite
3. Keep the Gemini key private. Never put it in frontend code or commit backend/.env.
4. Terminal 1, at the project root:
   npm install
   npm run dev
5. Terminal 2:
   cd backend
   npm install
   npm run dev
6. Open the localhost URL shown by Vite (normally http://localhost:5173).
7. Search a public GitHub username. Scroll to AI GitHub Studio to use the four additional AI tools. The analyzer is above it.

Backend health check: http://localhost:5000/api/health

If your AI Studio account uses a different currently available Gemini model ID, update GEMINI_MODEL in backend/.env and restart the backend.
See AI_FEATURES_SETUP.md for full instructions and troubleshooting.
